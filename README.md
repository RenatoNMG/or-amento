# CodeNextOn

Site institucional da CodeNextOn.

## Estrutura

- `index.html` — página principal e estrutura semântica.
- `assets/css/style.css` — identidade visual, layout e responsividade.
- `assets/js/main.js` — navegação, animações e comportamento do formulário.
